# BoardBrain

BoardBrain ist eine Progressive Web App für faire Zufallsentscheidungen und Statistik am Spieleabend, zunächst für Catan. Sie lost Personen, Reihenfolgen, Startplätze und Startrohstoffe nachweisbar fair aus, erfasst Ergebnisse und wertet sie aus. Alle Daten bleiben auf dem Gerät.

**Adresse:** <https://boardbrain.github.io/>
