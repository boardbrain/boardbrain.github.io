# BoardBrain

BoardBrain ist eine Progressive Web App für den Spieleabend. Bei Catan übernimmt sie fair und nachvollziehbar alle Zufallsentscheidungen beim Aufbau, bis hin zur zufälligen Platzierung der Startgebäude. Für Catan und eigene Spiele erfasst sie Ergebnisse und wertet sie je Gruppe aus. Die App läuft offline auf Smartphone, Tablet und PC; alle Daten bleiben auf dem Gerät.

**Adresse:** <https://boardbrain.github.io/>

## Stand

BoardBrain befindet sich in der Entwicklung. Unter der Adresse läuft bis zu Release 1.0 nur ein technischer Platzhalter (Version 0.1.0).
